# Screenshots / Captures d’écran

## Current gallery — OpenDente 0.8.0 (16)

Sixteen real screenshots supplied by **JulienEsbt on 26 October 2026**, captured on a MacBook Air M3 running macOS 27.2. The English and French READMEs show the main panel in their own language, in both light and dark appearance. The settings gallery also demonstrates the language picker, charging policy, storage mode, thermal controls, MagSafe signals, compact display and offline guide.

The PNG files are copied **byte for byte** from the supplied captures: no cropping, retouching, recompression, simulated values or changes to displayed measurements. Only their display size changes in Markdown; clicking an image opens the original resolution. Stable filenames identify each view, language and appearance.

The selection excludes detailed measurement/charger views containing hardware serial numbers, along with broader desktop captures. Unselected originals remain in the owner’s source folder and are not published here. Selected views show no visible account details or hardware serial numbers.

**Example settings, not prescribed defaults:** the images show a daily ceiling of 80%, resumption below 70% and a 35°C thermal threshold. The app’s thermal default is 40°C; the recorded daily charging cycle used 80/75%. A static screenshot does not establish whether a requested charging command has physically taken effect. Measurements, timings and test scope belong to [VALIDATION.md](../../VALIDATION.md).

Ces captures réelles illustrent la version 0.8.0 en français et en anglais, en clair et en sombre. Les PNG sont repris à l’identique. Les vues contenant des numéros de série ne font pas partie de la sélection publique. Les valeurs 80/70 % et 35 °C sont des exemples personnalisables, distincts des réglages par défaut et des conditions de validation matérielle.
