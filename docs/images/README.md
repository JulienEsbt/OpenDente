# Screenshots / Captures d’écran

## Current README gallery — 26 October 2026

Eight real screenshots supplied by JulienEsbt, showing **OpenDente 0.7.2 (15)** on a MacBook Air M3 running macOS 27.2. The English and French READMEs use the same files. The app interface is in French.

The PNG files are copied without cropping, retouching, recompression or changes to the displayed measurements. The README only scales their display; clicking a screenshot opens the original resolution. The selected views contain no visible account details or hardware serial numbers.

Original filenames follow `Capture d’écran 2026-10-26 à HH.MM.SS.png`. Stable English filenames are used in the repository so both READMEs share the same assets.

**Settings shown are examples, not fixed defaults:** the captures show a daily 80% ceiling, resumption below 70% and a 35°C thermal threshold. The app’s thermal default is 40°C; the recorded daily cycle validation used 80/75%. Static screenshots do not establish that a requested charge or thermal command has taken physical effect. The measurements, timings and hardware-test scope are recorded in [VALIDATION.md](../../VALIDATION.md).
